# HookRelay

Учебный сервис надежной доставки webhook-событий, написанный на Go.

Проект разрабатывается небольшими итерациями: сначала постановка задачи,
затем самостоятельная реализация, ревью и проверка понимания.

## Текущий этап

Этап 1: первый HTTP-сервер. Условия находятся в [`TASKS.md`](TASKS.md).

## Требования

- Go 1.24+
- Git
- Docker Desktop и Docker Compose (понадобятся с этапа PostgreSQL)

## Планируемые возможности

- REST API для endpoints и событий;
- конкурентная доставка через worker pool;
- PostgreSQL и надежная очередь;
- повторные попытки и история доставок;
- HMAC-подпись запросов;
- простой веб-интерфейс;
- Prometheus-метрики и структурированные логи.

Проект намеренно начинается без сторонних Go-зависимостей и без готового
каркаса сервера: первый исполняемый код должен написать автор проекта.
