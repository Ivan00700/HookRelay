# Учебные задания

## Этап 1 — первый HTTP-сервер

Цель: понять минимальный путь HTTP-запроса внутри Go-приложения.

### Перед написанием кода

Изучите документацию следующих элементов стандартной библиотеки:

- `http.NewServeMux`;
- `http.Server`;
- `http.ResponseWriter`;
- `*http.Request`;
- `os.Getenv`;
- `log.Printf`.

Не нужно читать весь пакет `net/http`: достаточно понять назначение этих
элементов и посмотреть их сигнатуры.

### Задание

Создайте файл `cmd/hookrelay/main.go`, который:

1. Читает переменную окружения `HTTP_PORT`.
2. Использует порт `8080`, если переменная отсутствует.
3. Создает собственный `http.ServeMux`.
4. Обрабатывает `GET /health`.
5. Возвращает HTTP 200, заголовок `Content-Type: application/json` и тело:

```json
{"status":"ok"}
```

6. Для `POST /health` возвращает HTTP 405.
7. Запускает сервер через явно созданный `http.Server`, а не через
   глобальный `http.ListenAndServe`.
8. Выводит в лог адрес, на котором стартует сервер.
9. Если сервер завершился с ошибкой, выводит ее и завершает процесс.

На этом этапе не добавляйте роутеры, конфигурационные библиотеки, middleware,
graceful shutdown или отдельные пакеты. Они появятся позже, когда станет ясно,
какую проблему каждый из них решает.

### Рекомендуемая форма

Нужны две функции, но их тела вы проектируете самостоятельно:

```go
func healthHandler(w http.ResponseWriter, r *http.Request)
func main()
```

### Самопроверка

Запустите приложение:

```powershell
go run ./cmd/hookrelay
```

В другом терминале проверьте:

```powershell
curl.exe -i http://localhost:8080/health
curl.exe -i -X POST http://localhost:8080/health
$env:HTTP_PORT = "9090"
go run ./cmd/hookrelay
```

Перед отправкой на ревью выполните:

```powershell
gofmt -w ./cmd/hookrelay/main.go
go vet ./...
go test ./...
```

### Критерии готовности

- сервер запускается на порту по умолчанию и на порту из окружения;
- `GET /health` возвращает ровно ожидаемый JSON;
- неподдерживаемый метод получает 405;
- код отформатирован и проходит `go vet`;
- вы можете своими словами объяснить роли `ServeMux`, handler,
  `ResponseWriter` и `Request`.
