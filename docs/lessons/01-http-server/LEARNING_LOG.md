# Журнал этапа 1

- Что я реализовал: HTTP-сервер с маршрутом `GET /health`, выбором порта из `HTTP_PORT` и JSON-ответом `{"status":"ok"}`. Для других HTTP-методов сервер возвращает статус 405.
- Как запрос проходит через программу: клиент создаёт и отправляет запрос; `http.Server` принимает его и передаёт в `ServeMux`; `ServeMux` выбирает зарегистрированный обработчик; `healthHandler` проверяет метод и через `ResponseWriter` формирует ответ клиенту.
- Что было непонятно или сломалось: сначала не было функции `healthHandler`; также путались роли `http.Server`, `ServeMux` и клиента. Отдельно разобраны `WriteHeader`, порядок заголовков и ранний `return`.
- Что теперь могу повторить без подсказки: создать `ServeMux`, зарегистрировать обработчик, прочитать порт из переменной окружения с запасным значением и запустить `http.Server`.
