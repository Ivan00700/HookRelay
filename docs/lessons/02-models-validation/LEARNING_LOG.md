## Часть 2A — модели и JSON

- Что я реализовал: модели `Endpoint`, `Event`, входные структуры для их создания и тип статуса доставки.
- Чем Go-структура отличается от JSON: структура задаёт поля и их типы внутри программы; JSON — текстовый формат для передачи данных.
- Как работают JSON-теги: задают имена полей в JSON; `json:"-"` исключает поле при кодировании и декодировании.
- Почему для payload выбран `json.RawMessage`: он сохраняет вложенный JSON-объект; `string` превратил бы его в строку с экранированными кавычками.
- Что было непонятно или сломалось: сначала назвал пакет `main`, скрыл секрет во входной структуре и выбрал строковые типы для payload, статуса и времени.
- Что теперь могу повторить без подсказки: описать структуры с JSON-тегами и объяснить, почему `CreateEndpointInput` принимает секрет, а `Endpoint` не показывает его в JSON-ответе.
